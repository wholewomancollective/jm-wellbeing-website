Resend, so you get an email when someone signs up

This is the one key you create. Resend is a free service that sends you a message each time someone signs up for The Morning Anchor.

  1. Go to resend.com and make a free account. Use the email address where you want the sign-up messages to arrive.
  2. In Resend, open the page called API Keys and create a key. Copy it straight away and keep that page open.
  3. Open the Secrets page of your Supabase account.
    Open the Secrets page
  4. Add two entries. Each has a name and a value. Then press Save.
    JACQUI_RESEND_KEY

    Value: the key you copied from Resend.

    JACQUI_NOTIFY_EMAIL

    Value: your email address, the same one you used for Resend.

The sign-up emails start once I have finished moving your sign-up storage into your Supabase. You can add the key before or after.

The one rule for keys

A key lives in one place only: that Secrets page. Never in a website file, an email, a message or a photo of your screen. Your website files are public, so Claude has been told never to put a key in them. If a key ever gets out, delete it in Resend and make a new one.
